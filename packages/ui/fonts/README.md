# Katagami fonts

Katagami Sans (UI text) and Katagami Mono (code) by Kevin Liu, version 1.3, under the SIL Open Font
License 1.1 in `OFL.txt`. The files are unmodified copies from https://katagami.kevinliu.studio:
each WOFF2 file from `/fonts/<file>` as linked by `/fonts/katagami.css`, and `OFL.txt` from
`/download/Katagami-1.3.zip`.

Only the main faces are bundled, normal and italic. They cover Latin, Greek, Cyrillic, and
symbols, with the same `unicode-range` as `katagami.css` (see `../src/fonts.css`). Text in other
scripts falls back to the system fonts named after Katagami in the theme's font variables.
